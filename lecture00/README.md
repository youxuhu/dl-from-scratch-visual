# 第0讲 引子：深度学习能做什么

## 这讲讲什么
用一个 28×28 的手写「7」引出问题：规则写不出来，只能从数据中学。再看深度学习的应用全景、整套课的路线图（预备讲 3 讲 + 正课 12 讲，两座高峰是第9、10讲的反向传播和第13、14讲的卷积网络），最后预演一次本套视频的讲法：`Y = np.dot(X, W) + b` 的逐格计算。

## 文件
| 文件 | 内容 | 对应台词段（out/B/scripts/L00.json） |
|---|---|---|
| pixel_seven.py | 用 NumPy 在 28×28 格子上画几种「7」和一个「T」，测试一条手写规则 | s001 到 s008、s014 |
| preview.py | 1×2 行向量乘 2×2 权重再加偏置 | s034 到 s039 |

## 怎么运行
```bash
cd lecture00
python pixel_seven.py
python preview.py
```

## 视频里出现的数值（都由脚本算出）
- 整齐的 7：第 5 行（行号从 0 开始）第 7 到 20 列一条横线，共 14 格；斜线到第 23 行第 11 列；全图亮格 32 个；拉直后 shape (784,)。
- 规则「第 5 行至少亮 10 格就是 7」：整齐的 7 14 格 True，歪的 7 13 格 True，短横的 7 6 格 False（漏判），带横杠的 7 14 格 True，T 14 格 True（误判）。
- 预告：X = [1.0, 2.0]，W = [[0.5, -0.2], [0.1, -0.6]]，b = [-0.4, 0.2]；np.dot(X, W) = [0.7, -1.4]，Y = [0.3, -1.2]。
