# 第13讲 卷积神经网络（上）：卷积层与池化层

## 这讲讲什么
CNN 的整体结构是「Conv、ReLU、Pooling」重复，再接「Affine、ReLU、Affine、Softmax」。全连接层把图片拉直会打散上下相邻的像素，卷积层则保留形状：滤波器在输入上滑动，对应格相乘再求和（乘积累加），再加偏置。然后讲填充、步幅和输出大小公式 OH = (H + 2P - FH) / S + 1，3 维数据（多通道）和批处理的卷积，形状约定 (N, C, H, W)，最后是 Max 池化：没有参数、通道数不变、对微小平移不敏感。

本讲以原理为主，用朴素 for 循环一格一格算；每个脚本最后都用 common 里的实现（im2col、Convolution、Pooling，下一讲细讲）核对结果。

### 依赖

- 第10讲：层的 forward 接口（common/layers.py）。
- 第14讲的实现提前拿来核对：common/util.py 的 im2col、conv_output_size，common/layers.py 的 Convolution、Pooling。
- 说明：conv2d_loops、conv_one_channel、max_pool_loops 是「从零写一遍」的教学演示版本，只在本讲使用；后面各讲 import 的是 common 里的 Convolution、Pooling。

对应鱼书：第7章 7.1到7.3节（书中这几节没有单独的源码文件；本讲脚本都是本仓库补充，用到的 Convolution、Pooling 对应书中 common/layers.py，im2col 对应 common/util.py）

## 视频里出现的数值（都由脚本算出）
- 输入 [[2,1,0,3],[1,3,2,0],[0,2,1,1],[3,0,1,2]]，滤波器 [[1,0,-1],[2,1,0],[0,1,1]]（本课自己设计的数）。
- 第一个窗口的 9 个乘积依次为 2、0、0、2、3、0、0、2、1，和为 10；输出 [[10, 8], [2, 11]]。
- 加偏置 3：[[13, 11], [5, 14]]。
- 填充 1：输出 4×4 的 [[6, 10, 4, 3], [2, 10, 8, 5], [0, 2, 11, 7], [1, 5, 2, 5]]。
- im2col 展开成 (4, 9)，乘拉直的滤波器，结果同样是 10、8、2、11。
- 输出大小：H=4、P=0、FH=3、S=1 得 2；P=1 得 4；H=7、FH=3、S=2 得 3；H=28、FH=5 得 24；H=28、P=2、FH=5 得 28。H=4、P=1、FH=3、S=2 除不尽，报错。
- 拉直：第10行第14列是第 294 格，第11行第14列是第 322 格，相隔 28。
- 3 通道卷积（滤波器 0）：三个通道各得 [[10, 8], [2, 11]]、[[0, 0], [0, 0]]、[[4, 3], [3, 4]]，相加为 [[14, 11], [5, 15]]；滤波器 1 只取中心，得 [[4, 3], [3, 2]]；两个滤波器叠成 (2, 2, 2)。
- 批处理：(10, 1, 28, 28) 经过 30 个 5×5 滤波器得到 (10, 30, 24, 24)。
- Max 池化：输入 [[7,1,6,0],[2,3,1,2],[1,0,2,1],[8,2,3,9]]，输出 [[7, 6], [8, 9]]；整体右移一格后输出 [[7, 6], [8, 3]]，4 格里 3 格不变。
